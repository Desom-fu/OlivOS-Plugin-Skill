# 生成插件的许可证

skill 本体是 MIT（见仓库根 `LICENSE`）。生成出来的插件按所用模板定许可证，
交付说明里要写明，不要沉默。

| 模板 | 插件许可证 | 原因 |
| --- | --- | --- |
| `official-native` | MIT | 官方模板只是文档化插件接口的最小实现，照文档自行实现同一套接口不构成衍生作品 |
| `light-plugin` | MIT | 上游 Light 模板是 MIT，且插件不必链接 OlivaDiceCore |
| `rule-plugin` | AGPL-3.0 | 规则插件链接 AGPL-3.0 的 OlivaDiceCore，分发结果必须 AGPL-3.0 兼容 |

## 调整规则

- 用户自带许可证时按用户的，但不能弱化依赖强制要求的许可。
- 在已有插件上二次修改时，沿用它原来的许可证。
- 跨两套模板时取更严格的那个。
- 如果确实大段照抄了上游 AGPL 代码而不是照文档重写，那个插件就沿用 AGPL。
